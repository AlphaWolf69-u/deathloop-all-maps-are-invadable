# All maps are invadable

Allows player invasions in all 14 regular district/time combinations, including those normally closed to invasions. Tutorials and ending areas are unchanged.

## Install

1. Download and extract latest Deathloop Mod Manager release from https://github.com/AlphaWolf69-u/deathloop-mod-manager/releases.
2. Click **Install mod** and select `AllMapsAreInvadable.zip`.
3. Check **All maps are invadable** in the installed-mod list.
4. Click **Launch game**.

To disable it, uncheck it and restart Deathloop. Installing a mod and enabling it are separate actions.
Modded public matchmaking is separate from vanilla matchmaking. Other players need the same enabled mods and versions. This mod allows invasions

## Build the package

Run `build.ps1`. Source lives in `mod/`; the resulting ZIP can be installed without changing the manager.
