# All maps are invadable

Allows player invasions in all 14 regular district/time combinations, including those normally closed to invasions. Tutorials and ending areas are unchanged.

## Install

1. Download and extract Deathloop Mod Manager 0.3.3 or later.
2. Click **Install mod** and select `AllMapsAreInvadable-1.0.2.zip`.
3. Check **All maps are invadable** in the installed-mod list.
4. Click **Launch game**.

To disable it, uncheck it and restart Deathloop. Installing a mod and enabling it are separate actions.

Both players must install the same mod package. To switch to this release, remove your existing installed mod, install this package, enable it, and restart the game. Both players must use this release to share its matchmaking pool.

Modded public matchmaking is separate from vanilla matchmaking. Other players need the same enabled mods and versions. This mod allows invasions; it does not force another player to join or remove every other matchmaking restriction.

## Build the package

Run `build.ps1`. Source lives in `mod/`; the resulting ZIP can be installed without changing the manager.
